# 扩展模式

官方原文：harness `docs/cookbook/extension-cookbook.zh.md`——harness 扩展的参考模式。代码片段省略了 import 和辅助实现，无法直接复制运行。系统与扩展点映射见 参考/概念 的[架构](../概念/架构.md)。

## 钩子插件（以权限门禁为例）

「原生钩子」是在拦截点上运行的普通 Cordis 插件，不需要外部协议：

```ts
import type { Context } from "@deepseek-ai/cordis";
import type { PreToolDecision, ToolExecution } from "@deepseek-ai/dsh-tools";

export const name = "permission-gate";

export function apply(ctx: Context) {
  ctx.on("tools/pre-execute", async (exec, next): Promise<PreToolDecision> => {
    if (!(await isAllowed(exec))) {
      return { kind: "deny", reason: "Denied by policy." };
    }
    return next();
  });
}
```

这个 waterfall 是**可重排的策略层**。选择规则：单调最终拒绝用 `ctx.tools.guard()`；包裹分发生命周期（超时/重试/指标）用 `tools/execute`；显式结果变换用 `tools/post-execute`；不可变最终结果的受限观察用 `tools/result`。详见 [Tool执行](../概念/Tool执行.md)。

## UI 插件

UI 插件从 `session/event` 事件流渲染（助手 token 流以 `assistant/chunk` 到达，加轮次/步骤边界与工具活动），通过 `agent.followup()` / `agent.steer()` 把输入驱动回去：

```ts
import type { Context } from "@deepseek-ai/cordis";
import { createUserMessage } from "@deepseek-ai/dsh-llm";
import { SessionId } from "@deepseek-ai/dsh-session";

export const name = "my-ui";
export const inject = ["agents"];

export function apply(ctx: Context) {
  ctx.on("session/event", (_session, event) => {
    if (
      event.type === "assistant/chunk" &&
      event.data.chunk.type === "text-delta"
    ) {
      render(event.data.chunk.text);
    }
  });
  onUserInput((text) =>
    ctx.agents.get(SessionId("client-session"))?.followup(
      createUserMessage({
        content: [{ type: "text", text }],
        source: { kind: "user" },
      }),
    ),
  );
}
```

浏览器插件要向内建 Web Client 贡献业务行时，注册 `ConversationNodeDefinition` 与 keyed Chat renderer（见 [新增ConversationNode](新增ConversationNode.md)）。

## 功能 → 机制映射（微内核声明）

每个产品功能都映射到文档化扩展点上的监听器——没有任何一行修改循环本身。

| 产品功能                   | 插件机制                                                                                                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 钩子系统（用户级+项目级）  | `agent/session-start`、`agent/pre-step`、`agent/request`、`tools/pre-execute`、`tools/post-execute`、`agent/turn-stopping` 上的监听器；waterfall 返回类型化决策，`agent/turn-stopping` 可 steering 触发下一步 |
| `/goal`                    | `ctx.goals` 管理持久状态 + 同会话 Round 驱动                                                                                                                                                                  |
| `/loop`                    | 在 `turn/end` 会话事件上 `followup()` 下一次迭代                                                                                                                                                              |
| 动态工作流                 | `ctx.workflowEngine` + worker-thread 引擎 + `workflow` 工具                                                                                                                                                   |
| 排队消息 + steering        | 核心 `Agent.followup()` / `Agent.steer()`                                                                                                                                                                     |
| 上下文压缩                 | `ctx.compaction` seam；压力检查在 serial `agent/pre-step`，溢出恢复在 `agent/request-error`                                                                                                                   |
| 系统提示词可配置性         | `ctx.systemPrompt.section()`，支持排序与作用域局部覆盖                                                                                                                                                        |
| 内置工具                   | `ctx.tools.register()`；schema 自动流入装配                                                                                                                                                                   |
| ToolSearch / 渐进式披露    | 可见集变化时替换作用域化的 `ctx.tools.restrict()` 注册                                                                                                                                                        |
| 工具截止时间/重试/指标     | `tools/execute` 包裹核心分发                                                                                                                                                                                  |
| 最终结果指标/审计/捕获     | `tools/result` 观察不可变权威结果                                                                                                                                                                             |
| 单调终端轮次策略           | 成功终端工具调用 `ToolExecution.concludeTurn()`                                                                                                                                                               |
| 子进程沙箱                 | `ctx.sandbox` 后端（dsh-bash-sandbox）；能力级拒绝用 `tools/pre-execute`                                                                                                                                      |
| 权限系统 / AskUserQuestion | `tools/pre-execute` 返回 `ask` + `ctx.approval` 应答                                                                                                                                                          |
| Plan mode                  | `plan/mode` 状态 + `plan:policy` 引导段 + `/plan` 入口                                                                                                                                                        |
| subagent 委派              | `ctx.subagents` 提供方注册表 + `dsh-tool-subagent`                                                                                                                                                            |
| MCP                        | 每个服务器一个插件：发现工具 → `ctx.tools.register()`                                                                                                                                                         |
| skill（技能）              | section + 工具注册；调用时 `inject()` 注入 skill 内容                                                                                                                                                         |
| 定时任务（cron）           | 注册面向模型的调度工具；空闲时 `followup()` / 忙碌时 `inject()` 通知                                                                                                                                          |
| UI                         | 监听 `session/event`（分片、边界、工具活动）；输入 → `followup()`                                                                                                                                             |
| Web Client Chat 业务节点   | `ConversationNodeDefinition` + `conversation.chat.node` keyed renderer                                                                                                                                        |
| 遥测/可回放 trace          | `session/event` → JSONL；回放 = `sessions.create(id, { seed })`                                                                                                                                               |
| 模型适配器                 | `registerAdapter` 注册 `LlmAdapter` 子类                                                                                                                                                                      |
| 插件热重载                 | 每个注册都是 `ctx.effect` → HMR 直接生效                                                                                                                                                                      |

`system-prompt/assemble` 是专家协作式的整体装配变换：返回的装配结果具有权威性，监听器作者有责任保留活跃 Code Mode 与结构化输出协议的贡献。

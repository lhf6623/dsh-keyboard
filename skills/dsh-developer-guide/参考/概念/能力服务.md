# 能力服务

官方原文：harness `docs/capability-seams.zh.md`（全量清单含实现包、消费方与 mermaid 图；下表是插件开发常用子集，完整版以官方文档为准）。

## seam 三角色

服务可以是核心主干服务、可替换的能力 seam，或组合包/组合点。一个 **seam** 是含三种角色的可替换能力：**Service Definition**（拥有自身 `ctx.<key>` 和词汇类型的 Cordis Service——可以是抽象类或具体注册表，绝不是 TS interface）、一个或多个 **Service Provider**、一个或多个注入该服务的 **Consumer**。seam 是完整能力，绝不是其中一个角色；能力成员按其角色/类/服务/约定/扩展点命名。

`packages/shell` 是规范范例：`dsh-shell`（Definition）、`dsh-bash-local`/`dsh-bash-sandbox`（Provider）、`dsh-tool-bash`（Consumer）。角色独立演进时通常不同包；同一关注点时一个包可承担多角色（`dsh-llm` 同时是 Definition 和 Consumer）。

## 插件开发常用的 ctx 键

| ctx 键 | 角色 | 说明 |
| --- | --- | --- |
| `ctx.tools` | core | 工具注册表与带把关的执行流水线（注册、pre/post 策略、守卫、环绕分发、最终结果） |
| `ctx.systemPrompt` | core | 每步收集提示词片段和面向模型的工具 schema |
| `ctx.llm` | seam | LLM 适配器注册表；提供方实现流服务 |
| `ctx.agents` | core | 活跃 Agent 句柄、创建/恢复工厂 seam、进程本地发起方传播 |
| `ctx.sessions` | core | 仅追加 Session 实例 + 持久会话事件流 |
| `ctx.sessionPersistence` | seam | 各后端持久化同一套 SessionEvent 词汇（jsonl/sqlite），组合时选择后端 |
| `ctx.sessionQuery` | seam | 会话精确读取、过滤、追踪 |
| `ctx.settings` | seam | 插件注册 namespace schema 并解析分层值；提供方存储原始文档；Web 网关提供脱敏描述符并写用户层 |
| `ctx.credentials` | seam | 配置携带机密引用；提供方拥有实际值；消费方按操作解析 |
| `ctx.webServer` | core | node:http 载体：具名路由注册表、索引转换 tap、静态 dist 回退 |
| `ctx.apiProxy` | core | 与传输无关的 Host 网关：分派浏览器 API 调用，每条 Host 流自行订阅转发事件 |
| `ctx.clientModules` | core | 增量扫描组合 `dsh.client` 入口图，提供插件组合包，通知重建/图变更 |
| `ctx.commands` | core | 面向人的命令注册（斜杠指令，不经模型轮次分派） |
| `ctx.approval` | seam | 一次性权限决策经 `approval/request` waterfall 分派；无应答方时以 unavailable 失败 |
| `ctx.planMode` | core | 折叠已记录的计划/模式状态，注册 /plan |
| `ctx.skills` | seam | 合并提供方的 skill 目录 |
| `ctx.subagents` | seam | subagent 提供方注册表（in-process/fork/acp/codex/claude-code/dsh-sdk） |
| `ctx.goals` | core | 同会话目标领域（/goal） |
| `ctx.shell` | seam | Bash 执行器 seam；bash-local/bash-sandbox/pwsh-local 可替换 |
| `ctx.subprocess` | seam | 进程坐标、进程树/会话生命周期、stdio 处置、kill 升级 |
| `ctx.terminals` | seam | 持久 PTY 会话注册表 |
| `ctx.sandbox` | seam | 进程沙箱 seam；消费方交出即将 spawn 的确切 argv |
| `ctx.fs` | seam | 文件系统提供方 seam（fs-local/fs-sandbox/fs-e2b） |
| `ctx.compaction` | seam | 上下文压缩 seam；压力检查在 `agent/pre-step`，溢出恢复在 `agent/request-error` |
| `ctx.workflowEngine` | seam | 工作流脚本引擎（每上下文一个引擎，无具名提供方注册表） |
| `ctx.jobs` | seam | 后台作业注册表（后台 bash、PTY 发送、subagent 委派登记；tool-jobs 读取/停止） |
| `ctx.web` | seam | 搜索与抓取提供方注册到同一 seam；tool-web 负责稳定的面向模型名称 |
| `ctx.storage` | seam | 非会话存储枢纽；领域形态挂到 `ctx.storageDomain` |
| `ctx.sessionTitle` | seam | 日志背书的会话标题；唯一可选异步提供方注册 |
| `ctx.userQuestions` | seam | 人类问答 seam；UI 前端提供当前生效的人工回答提供方 |
| `ctx.sessionProjections` | core | 状态驱动的折叠单元（todo、标题等）；api-proxy 提供基线并推送变化 |

宿主与浏览器双端可用的完整清单、实现包与消费方见官方 `docs/capability-seams.zh.md`（维护模式：混合，从 Cordis 声明自动发现）。

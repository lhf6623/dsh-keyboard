# 7. 进入 Harness

官方原文：harness `docs/cordis-tutorial/07-into-the-harness.zh.md`。

本章向 harness 的 `tools` 服务注册一个模型可调用的工具，通过真实工具流水线执行并观察结果事件。示例无需密钥、不调用模型。

## 工具插件

```ts
import type { Context } from "@deepseek-ai/cordis";
import { defineTool } from "@deepseek-ai/dsh-tools";
import { CallId } from "@deepseek-ai/dsh-llm";

export const name = "greet-tool";
export const inject = ["tools"];

export function apply(ctx: Context) {
  ctx.tools.register(
    defineTool({
      name: "greet",
      description: "Greet the named person.",
      parameters: {
        name: { type: "string", required: true, description: "Who to greet" },
      },
      output: {
        schema: { type: "string" },
        render: (_args, value) => [{ type: "text", text: value }],
      },
      async execute(args) {
        return `Hello, ${args.name}!`;
      },
    }),
  );

  // 无模型手动驱动一次真实执行流水线（模型角色由你暂代）。
  // CallId 给关联 id 打品牌。
  void (async () => {
    const result = await ctx.tools.execute({
      callId: CallId("demo-1"),
      name: "greet",
      arguments: { name: "Cordis" },
      signal: new AbortController().signal,
    });
    console.log("tool replied:", JSON.stringify(result.content));
  })();
}
```

每个模式都来自前几章：`inject: ['tools']` 等待注册表就绪；`ctx.tools.register(...)` 把注册 disposer 附着到插件（卸载时注销）；`defineTool` 把 `parameters` 转成展示给模型的 JSON Schema、推导 `args` 类型并在 `execute` 前校验参数；工具返回 `output.schema` 声明的规范值，`output.render` 作为 Native renderer 生成可持久化的结果内容。

## 观察插件

```ts
import type { Context } from "@deepseek-ai/cordis";
import type {} from "@deepseek-ai/dsh-tools"; // 引入该包的声明合并，事件与 payload 获得类型

export const name = "tool-logger";
export const inject = ["tools"];

export function apply(ctx: Context) {
  ctx.on("tools/result", (exec, result) => {
    const text = result.content
      .map((block) => (block.type === "text" ? block.text : ""))
      .join("");
    console.log(`[tool-logger] ${exec.name} -> ${text}`);
  });
}
```

## 组合并运行

```yaml
- name: "@deepseek-ai/dsh-system-prompt"
- name: "@deepseek-ai/dsh-tools"
- name: "./tool-logger.ts"
- name: "./greet-tool.ts"
```

`@deepseek-ai/dsh-tools` 注入 `systemPrompt` 服务（工具需要向系统提示词贡献 schema），所以组合里也要列出它的提供方；缺少时工具插件保持 PENDING（第 6 章）。

```
[tool-logger] greet -> Hello, Cordis!
tool replied: [{"type":"text","text":"Hello, Cordis!"}]
```

logger 先触发：`tools/result` 在结果物化过程中发出，早于 `execute` 向调用方返回的 promise 兑现。两个插件互相不知道对方存在，由注册表服务与事件连接。

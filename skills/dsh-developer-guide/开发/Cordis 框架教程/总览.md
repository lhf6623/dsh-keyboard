# 总览

官方原文：harness `docs/cordis-tutorial/index.zh.md`。

Cordis 是 DeepSeek Harness 底层的插件框架：一个小型运行时，其中的每项能力（工具、LLM 适配器、文件访问乃至 agent loop 本身）都是挂载到共享上下文中的插件。本教程通过动手实践讲解 Cordis——每一章都是可运行的例子，在临时目录中逐步构建，最后一章把插件接入真实 harness。

## 准备工作

本教程不需要 API 密钥，所有示例均可无密钥运行：

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
mkdir -p tmp/cordis-tutorial
cd tmp/cordis-tutorial
```

每一章都从该目录运行同一条命令：

```sh
node --import tsx ../../vendor/cordis/bin.js
```

这个单文件启动器创建根 `Context`、挂载 Loader 插件，并让它从当前目录加载 `./cordis.yml`。其余一切（有哪些插件、如何配置）都来自你写的 YAML。`--import tsx` 让 Node 无需构建步骤即可运行配置指向的 TypeScript 文件。

## TypeScript 说明

示例只用普通现代 JavaScript 之外的三项 TS 功能：

- **类型注解**描述值但不改变运行时行为（`ctx: Context`、`who: string`、`string[]`）。
- **`import type { Context } from '@deepseek-ai/cordis'`** 只导入类型，运行时消失；纯类型注解的插件文件不增加运行时依赖。
- **声明合并**（`declare module '@deepseek-ai/cordis' { ... }`）给 Cordis 已声明的接口添加条目（新 `ctx.greeter` 属性、事件名）。它不生成任何运行时接线——插件必须另行提供服务或发出事件。

第 5 章还会用到 `interface` 描述配置对象字段、`Schema<Config>` 泛型表示 schema 校验哪些字段。

如果你要为 harness 本身编写插件（由 cordis.yml 加载、在 Web UI 中驱动），从 开发/基础 的[第一个插件](../基础/第一个插件.md)开始；本教程的启动器是教学用的极简组合。

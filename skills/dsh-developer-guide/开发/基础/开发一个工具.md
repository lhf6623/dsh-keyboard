# 开发一个工具

官方原文：harness `docs/user/develop/basic/tool.zh.md`；工具编写参考（嵌套 schema、规范值、后台工作、策略钩子、Code Mode、UI 卡片）：`docs/cookbook/adding-a-tool.zh.md`。

## 工具插件

```ts
import type { Context } from '@deepseek-ai/cordis'
import { defineTool } from '@deepseek-ai/dsh-tools'

export const name = 'greet-tool'
export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.tools.register(defineTool({
    name: 'greet',
    description: 'Greet someone by name.',
    parameters: {
      name: { type: 'string', required: true, description: 'The name to greet' },
    },
    output: {
      schema: { type: 'string' },
      render: (_args, value) => [{ type: 'text', text: value }],
    },
    async execute(args) {
      return `Hello, ${args.name}!`
    },
  }))
}
```

- `inject: ['tools']` 让 Cordis 等工具注册表就绪；`ctx.tools.register(...)` 的 disposer 附着到插件，卸载时自动注销。
- `defineTool` 把 `parameters` 规约转成展示给模型的 JSON Schema，推导 `args` 类型，并在 `execute` 运行前校验模型提供的参数。
- `execute` 返回 `output.schema` 声明的**规范值**；`output.render` 作为 Native renderer，把规范值转成面向模型、可持久化的结果内容（如 `[{ type: 'text', text }]`）。
- `ctx.tools.register()` 也直接接受原始 JSON Schema `ToolDefinition`（MCP 来源的工具就是这样到达的）；`defineTool` 是第一方工具使用的类型化辅助函数。

## 无模型驱动一次调用

用真实执行流水线手动驱动，模型角色由你暂代；`CallId` 给关联 id 打品牌：

```ts
import { CallId } from '@deepseek-ai/dsh-llm'

const result = await ctx.tools.execute({
  callId: CallId('demo-1'),
  name: 'greet',
  arguments: { name: 'Cordis' },
  signal: new AbortController().signal,
})
```

## 观察工具调用

监听 `tools/result` 观察每次调用（结果物化期间发出，早于 `execute` 的 promise 兑现）：

```ts
import type { Context } from '@deepseek-ai/cordis'
import type {} from '@deepseek-ai/dsh-tools'   // 引入声明合并，事件与 payload 获得类型

export const name = 'tool-logger'
export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.on('tools/result', (exec, result) => {
    const text = result.content
      .map(block => block.type === 'text' ? block.text : '')
      .join('')
    console.log(`[tool-logger] ${exec.name} -> ${text}`)
  })
}
```

## 策略钩子与观察（进阶，详见 adding-a-tool）

- `tools/pre-execute`（waterfall）——返回 `{ kind: 'deny', reason }` / `{ kind: 'ask' }` 类型化决策做权限门禁；可重排的策略层。
- `ctx.tools.guard()` —— 不变式需要单调最终拒绝时使用。
- `tools/execute` —— 包裹实际分发生命周期（超时/重试/指标；仅 `exec.signal` 可替换）。
- `tools/post-execute` —— 显式结果变换；`tools/result` —— 对不可变最终结果的受限观察。
- 展示/查找/执行对齐的工具过滤用 `ctx.tools.restrict()`。

## 组合时注意

`@deepseek-ai/dsh-tools` 注入 `systemPrompt` 服务（工具要向系统提示词贡献 schema），组合中要有该服务的提供方（harness 的 web profile 已含）；缺少时工具插件保持 PENDING。

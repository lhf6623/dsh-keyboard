# 事件系统

官方原文：harness `docs/user/develop/framework/events.zh.md`；动手版：`docs/cordis-tutorial/04-events.zh.md`。

## 基本用法

```ts
// 监听
ctx.on('event-name', (payload) => { /* ... */ })
// 发出
ctx.emit('event-name', payload)
```

事件让插件无需知道谁在监听就能发出通知。harness 用它处理工具结果、模型请求、审批决定等交互。

## 五种分发模式

每个事件有且只有一种分发模式，是事件公开约定的一部分：

| 模式 | 调用 | 语义 |
| --- | --- | --- |
| emit | `ctx.emit(name, ...args)` | 同步广播，监听器按注册顺序观察，返回值被忽略 |
| parallel | `await ctx.parallel(name, ...args)` | 所有监听器并行，全部等待 |
| serial | `await ctx.serial(name, ...args)` | 按序等待；第一个非 null/false/undefined 返回值胜出并停止 |
| bail | `ctx.bail(name, ...args)` | serial 的同步版 |
| waterfall | `ctx.waterfall(name, ...args, next)` | 环绕中间件，见下 |

## waterfall：变换或短路

waterfall 是实现拦截的模式。每个监听器收到参数和一个 `next()` continuation，可包装下游返回值，也可不调用 `next()` 直接返回而**短路**链条。

> **纪律**：只观察/标注的 waterfall 监听器**必须调用 next()**；不调用 = 有意短路。日志监听器忘了 next() 会悄无声息吞掉下游全部默认行为。harness 用 waterfall 实现策略决策：`tools/pre-execute`（返回 deny/ask 决策）、`approval/request`、`agent/request` 等。

## 类型安全的事件：声明 → 发出 → 监听

```ts
// 发出方（拥有该事件的服务/插件）：
// 1. 声明合并——事件名 + 监听器签名，ctx.emit / ctx.on 两边都拿到类型
declare module '@deepseek-ai/cordis' {
  interface Events {
    'stats/report'(name: string, count: number): void
  }
}
// 2. 发出——参数与 Events 里声明的签名一致
ctx.emit('stats/report', name, count)

// 监听方：
// 3. 空导入——不产生运行时依赖，只为让 TypeScript 看到声明合并
//    （跨包时 import type {} from '@deepseek-ai/dsh-xxx'，dsh 各包都带声明合并）
import type {} from './stats.ts'
ctx.on('stats/report', (name, count) => { /* ... */ })
```

事件名遵循 `namespace/action` 约定（`agent/step`、`tools/result`、`session/event`）。

## Cordis 事件与会话记录

`turn/*`、`step/*`、`tool/call`、`tool/result`、`compaction/*` 是**持久化的会话事件类型，不是同名 Cordis 事件**。需要观察它们时，监听 Cordis 事件 `session/event` 并检查 `event.type`：

```ts
ctx.on('session/event', (session, event) => {
  if (event.type === 'turn/end') { /* AI 回答完毕 */ }
})
```

信封是 `{ type, seq, time, data }`——payload 在 `event.data` 里；`session/event` 只在 live append 时发出，恢复/回放的历史事件不重放。完整类型词表见 参考（会话事件）。

## 事件监听器也是效果

`ctx.on()` 注册的监听器在插件卸载时自动移除，绝不需要手动维护 removeListener。

## 示例：工具日志插件

```ts
import type { Context } from '@deepseek-ai/cordis'
import type {} from '@deepseek-ai/dsh-tools'

export const name = 'tool-logger'
export const inject = ['tools']

export function apply(ctx: Context) {
  ctx.on('tools/result', (exec, result) => {
    const text = result.content
      .map(block => block.type === 'text' ? block.text : '')
      .join('')
    console.log(`[tool] ${exec.name} -> ${text.slice(0, 100)}`)
  })
}
```
